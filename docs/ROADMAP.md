# Hive 重构路线

## 原则

- 一个阶段只交付一个可验收的垂直切片。
- 协议优先于实现；实现优先于优化。
- 任何阶段完成都必须有真实测试或检查证据。
- 只有 H00 可以修改共享白板和冻结契约。

## 阶段

| 阶段 | 交付 | 进入条件 |
|---|---|---|
| H01 | 契约、workspace、基础类型、配置、doctor CLI | H00 冻结范围 |
| H02 | SQLite、迁移、事件日志、游标、恢复 | H01 验证通过 |
| H03 | 工具、审批、路径/网络/Shell 安全 | H01 验证通过 |
| H04 | 单 Agent 模型/工具闭环 | H02、H03 完成 |
| H05 | 并行 DAG 调度、租约、取消、预算 | H04 完成 |
| H06 | 多 Agent 交接、worktree、集成者 | H05 完成 |
| H07 | OpenAI/Magpie 网关、流式、路由 | H01 完成，可与 H02 并行 |
| H08 | HTTP/SSE/JSON-RPC、Web 控制台 | H05、H07 完成 |
| H09 | 定时、可观测性、数据生命周期 | H02、H08 完成 |
| H10 | 评估、故障注入、性能与安全 | H06 完成，基准脚手架可提前 |
| H11 | 安装、迁移、兼容、回滚、发布 | H10 通过 |

## 并行规则

- 最多两个实现对话同时写代码。
- 第三个并行对话只能是只读审计或独立测试脚手架。
- 两个实现对话不得修改同一 crate、同一迁移目录或同一协议文件。
- 并行前必须有稳定基线 commit；没有基线时只允许本地顺序修改。

## 共同退出标准

- 规定的命令真实运行。
- 没有越界文件改动。
- 协议变化有 ADR。
- handoff 能让下一个对话在不读取旧聊天记录的情况下接手。
