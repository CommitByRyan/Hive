# H06 — 多 Agent 协作与 worktree

> 状态：implemented, verified（结构化 Handoff、V4 迁移、租约复用、worktree 生命周期）

## 目标

消除 AgentRunner 双重租借、实现结构化 Handoff 与独立 worktree 生命周期，让两个 Builder 在独立 worktree 修改代码而不互相污染。集成者自动合并、冲突检测与 worktree 回收策略留 H06b。

## 交付内容

### `hive-types`

- 新增 `HandoffId`（前缀 `hd_`），`IdPrefix::Handoff`，`ID_PREFIXES` 扩到 12 项。
- 新增 `EventKind::HandoffCreated`（`handoff.created`），同步 `as_str`/`parse`。
- 新增 `Handoff` 及 `HandoffArtifact`/`HandoffDecision`/`HandoffProvenance`，字段严格对齐 PROTOCOL §5。
- `Handoff::validate()`：`agent`/`objective`/`summary`/`provenance.base_revision`/`provenance.created_at` 非空，`schema_version == HANDOFF_SCHEMA_VERSION`，artifact `sha256` 为 64 位 hex，`summary ≤ 8 KiB`。
- 新增 `HANDOFF_SUMMARY_MAX_BYTES = 8 * 1024`。

### `hive-store` migration V4

- `SCHEMA_VERSION = 4`，新增 `V4_SCHEMA`：`handoffs` 表按 §10 V4 列契约，`UNIQUE(node_id, attempt_no)`。
- `insert_handoff(&Handoff) -> HandoffRecord`：先校验，行插入与 `handoff.created` 事件同事务提交。
- `get_handoff(node_id, attempt_no)`、`list_handoffs(mission_id)`。
- 迁移链只追加：V1/V2/V3 SQL 未改；`V3_SCHEMA`/`V4_SCHEMA` 升为 `pub(crate)` 供迁移测试复用。
- 导出 `now_ms`/`now_rfc3339`/`rfc3339_from_ms` 供 `hive-agent` 构造 provenance 时间戳。

### `hive-agent`

- `AgentRunner::run_node_with_lease(session, node, guard, spec, cancel)`：不再自己 `lease_node`，直接用调度器给的租约；`run_node` 保留为「先领取再调用」的包装，避免破坏既有调用方。
- `AgentOutcome::Completed` 时构造并校验 Handoff，调用 `insert_handoff`，把 `handoff_id` 写进 `node.succeeded` 事件 payload。

### 新建 `crates/hive-workspace`

- `WorktreeManager { project_root, base_dir }`，`base_dir` 默认 `<project>/.hive/worktrees`。
- `create(node, base_ref) -> WorktreeHandle`：`git worktree add -b hive/<node-slug> <path> <base_ref>`；同名失败返回 `AlreadyExists`。
- `list()`：解析 `git worktree list --porcelain`，只保留 `base_dir` 下的 worktree。
- `remove(handle, force)`：默认不加 `--force`，脏工作区必须显式 `force`。
- 安全：路径必须落在 `base_dir` 内；拒绝把 `project_root` 本身当 worktree；所有 git 调用用 argv 数组（`std::process::Command`），不拼字符串、不引第三方 git 库。

## 验收

- Handoff 落库与 `handoff.created` 事件同事务，`UNIQUE(node_id, attempt_no)` 冲突被拒。
- 外部租约下 `run_node_with_lease` 不产生第二个 lease；租约不匹配返回 `StaleExecution`。
- 两个 worktree 分别写不同文件互不污染；脏工作区 `remove` 无 `force` 拒绝；路径越界与 project root 被拒。
