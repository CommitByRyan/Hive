# H03b-4 — fs.* 句柄级读写与安全原子替换

> 状态：ready after H03b-3 merge；基线以合并后 main 为准。
> 依据：R08 P2-2、H03b-2 平台原语、`docs/design/H03-tool-security.md` §2/§3。

## 目标

把 `fs.read` / `fs.write` / `fs.list` 从「字符串授权后按路径重新打开」切换为「授权与读写使用同一对象句柄」，关闭检查后替换的 TOCTOU 窗口；`fs.write` 继续保持「同目录临时文件 + 原子替换」，不得退化为直接覆盖目标。

## 允许范围

- `crates/hive-platform`：为已授权的 `PathHandle` 增加受控 IO/枚举/替换原语；不得放宽 H03b-2 已冻结的逐段遍历、reparse 拒绝、最终路径与卷序列校验。
- `crates/hive-tools`：`fs.read`/`fs.write`/`fs.list` 的 prepare/execute、错误映射、测试与 `docs/runbooks/H03b.md` 实测结果。
- `crates/hive-policy`：仅在需要稳定错误码映射时调整，不得放宽 `PathPolicy`。

禁止：改 `hive-store`/`hive-runtime`/`hive-server`/迁移/PROTOCOL/ADR/白板；不改 `shell.run` 与出网路径；不改 `fs.write` 的「临时文件 + 替换」语义；不新增第三方依赖（只可使用现有 `windows-sys` feature）。

## 交付

1. **句柄所有权**
   - `PathHandle` 提供受控的 `into_file(self) -> std::fs::File`（Windows 用 `FromRawHandle` 后 `mem::forget(self)`，避免 double-close；非 Windows 用 `path()` 打开并明确 capability 降级）。
   - 任何 `fs.*` 执行路径不得在授权后再次按 `final_path` 打开同一目标；`fs.read` 必须从授权返回的同一句柄读取。
2. **fs.read**
   - `prepare` 保留只读 `PathHandle`；`execute` 读取该句柄，有界读取/截断/UTF-8 lossy 语义与现有测试一致。
   - 增加测试：授权后把原路径替换成另一个文件，读取内容仍来自已授权对象。
3. **fs.write 安全原子替换**
   - 目标父目录必须由句柄级遍历验证并保持打开到替换结束；临时文件用 `CREATE_NEW` 在同一父目录创建，写完 `sync_all` 后再替换。
   - Windows 目标存在时优先 `ReplaceFileW`；目标不存在时用 `MoveFileExW(MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`；优先使用句柄相对的 `SetFileInformationByHandle` rename。若本阶段只能做路径级 replace，必须：
     - 替换前后校验父目录 `file_id`/卷序列未变；
     - 在 `PathCapabilities.note` 明确残余窗口，不得宣称完全句柄级。
   - 失败时必须清理临时文件、不得破坏旧目标；读取方只能看到旧内容或新内容，不能看到半写状态。
4. **fs.list**
   - 目录授权必须使用目录句柄；Windows 子项枚举使用该句柄（`GetFileInformationByHandleEx(FileIdBothDirectoryInfo)` 或等价），不得在授权后按字符串重新打开目录。
   - 非 Windows 允许回退到 `read_dir(final_path)`，但必须在 `PathCapabilities`/handoff 中声明 `listing_handle_relative=false`，不得静默等同。
5. **能力矩阵**
   - 只有 `hive-tools` 的 fs.* 真正走句柄后，才可声明「fs.* 已接句柄级」；`path_capabilities().handle_level` 仍只描述平台原语，不自动代表接线完成。
   - `fs.write` 的原子替换能力单独列出，不与路径隔离能力混写。

## 测试

| 用例 | 要求 |
|---|---|
| `fs_read_reads_from_authorized_handle_after_path_swap` | `prepare` 后替换路径目标，`execute` 仍读到旧对象内容 |
| `fs_write_replaces_atomically_and_keeps_temp_clean` | 旧/新内容二选一可见；无 `.hive-tmp-*` 残留 |
| `fs_write_cleans_temp_when_replace_fails` | 目标为目录或替换失败时旧目标不变、临时文件清理 |
| `fs_write_rejects_junction_parent_before_temp_creation` | Windows junction 父目录在创建临时文件前拒绝；无 NTFS 环境打印 SKIP |
| `fs_list_uses_authorized_directory_handle` | Windows 走句柄枚举；非 Windows 明确 capability=false |
| `path_handle_into_file_keeps_single_owner` | 句柄转交后只关闭一次，无 double-close/泄漏 |

既有 `fs_read_is_bounded_and_audits_three_events`、`fs_read_truncates_at_limit`、`fs_read_rejects_traversal_before_execution`、`fs_write_uses_temp_file_and_atomic_rename`、`fs_write_requires_approval_and_does_not_create_file`、`fs_list_returns_sorted_bounded_entries` 不得退化；H03b-2 的 `open_checked`/`create_file`/junction 测试不得退化。
