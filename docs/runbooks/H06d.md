## H06d-1：集成器（`hive-workspace` only）

允许范围：`crates/hive-workspace/src/`、其测试、本 runbook。不得改 `hive-agent`/`hive-runtime`/协议/迁移。

交付：

1. `head_revision(&WorktreeHandle) -> Result<String, WorkspaceError>`：`git -C <path> rev-parse HEAD`，返回 40/64 位 hex；失败结构化报错。
2. `status(&WorktreeHandle) -> Result<WorktreeStatus, WorkspaceError>`：解析 `git status --porcelain`，至少给出 `dirty: bool`。
3. `preview_merge(&self, target_ref: &str, branch: &str) -> Result<MergePreview, WorkspaceError>`：
   - 在 `project_root` 执行 `git merge-tree --write-tree <target_ref> <branch>`（Git ≥ 2.38，本机 2.52）；
   - 返回 `Clean { tree }` 或 `Conflicts { paths }`；
   - 不修改工作区、不创建 merge commit。
4. `merge(&self, target_ref: &str, branch: &str, message: &str) -> Result<MergeOutcome, WorkspaceError>`：
   - 先检查 `project_root` 工作区干净，脏则拒绝；
   - 先 `preview_merge`，有冲突直接返回 `Conflicts`，目标分支不变；
   - 干净才 `git merge --no-ff <branch>`，返回 `Merged { commit }`；
   - 禁止 `--force`、禁止 `reset`、禁止自动解决冲突。
5. `recycle(&self, handle, policy)`：`policy.keep_dirty=true` 时脏 worktree 保留并返回 `KeptDirty`，否则调用既有 `remove`；失败不得静默。

测试（真实临时 Git 仓库）：

- `two_worktrees_merge_cleanly_when_files_differ`；
- `preview_merge_reports_conflict_and_does_not_touch_target`；
- `merge_refuses_dirty_project_root`；
- `head_revision_returns_hex_sha`；
- `recycle_keeps_dirty_worktree_when_policy_says_so`。

完成标准：`pwsh -NoProfile -File scripts/verify.ps1` 全绿；既有 `hive-workspace` 5 条测试不退化；提交 `feat: H06d-1 worktree 集成器与回收策略`。
