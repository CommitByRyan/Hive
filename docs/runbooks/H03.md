# H03 — 工具与工作区安全

> 状态：implemented；shell 真实执行留 H03b。
> 基线：`9380fc3`。本轮提交见 `git log -1`。

## 目标与边界

建立统一工具入口 `validate -> policy -> approval -> execute -> audit`，先落应用层路径/网络策略、审批消费和审计链，不把应用层校验宣传为 OS 沙箱。

本轮交付：

- `crates/hive-policy`：稳定错误码、`PathPolicy`、`NetworkPolicy`、`ToolSpec`/`ToolRegistry`、规范化请求 SHA-256。
- `crates/hive-tools`：`ToolDispatcher`、`fs.read`、`fs.write`、`fs.list`、禁用版 `shell.run`、事件审计适配。
- `crates/hive-store`：V2 迁移 `tool_calls` / `artifacts` / `tool_audit`，`consume_approval` 单事务 CAS，审计哈希链追加与校验。
- 根 `Cargo.toml` 只增加 `hive-policy`、`hive-tools` 两个 member。

## 降级声明

1. **路径不是句柄级安全。** `PathPolicy` 使用 `canonicalize + 目录段复核`，在检查和调用方打开之间存在 TOCTOU 窗口；未使用 `FILE_FLAG_OPEN_REPARSE_POINT`、`GetFinalPathNameByHandleW` 或根句柄遍历。不能宣称阻止并发替换 junction/symlink 或 8.3 短名绕过。
2. **symlink 与句柄级用例显式跳过。** `policy_rejects_symlink_escape` 标记 `#[ignore = "symlink creation needs Windows developer mode or elevation"]`；`open_handle_detects_toctou_swap` 标记 `#[ignore = "H03 uses canonicalize + recheck; handle-level TOCTOU defense is not implemented"]`。本轮不据此声称 Windows symlink/junction 或句柄级验收完成。
3. **Shell 未实现真实执行。** `shell.run` 固定返回 `shell.disabled`，不 spawn、不做 argv 校验、不做超时/进程树清理；这些属于 H03b。
4. **网络只有纯策略分类。** 已实现默认拒绝、域名/端口 allowlist、解析 IP 分类与 IPv4-mapped 处理；未实现 DNS 解析、连接级 IP 固定、TLS SNI/peer 复核、重定向逐跳校验，不能宣称已防 DNS rebinding。
5. **审批消费未接入 dispatcher。** `Store::consume_approval` 已实现单事务 CAS；dispatcher 通过 `ApprovalGate` 抽象，当前生产默认是 `DenyApprovals`，`AllowAllApprovals` 仅测试用，H04 负责接入 store 审批与执行闸门。
6. **审计链未与每次调用自动同事务写入。** dispatcher 写 `node.tool_call` / `node.tool_started` / `node.tool_result` 事件；`tool_audit` 哈希链提供追加与校验 API，后续由 H04/H09 接入完整审计记录与检查点。
