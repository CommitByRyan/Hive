# H03 — 工具与工作区安全

> 状态：blocked until H01

## 目标

实现统一工具调用入口、审批、路径沙箱、网络策略、Shell 开关、产物登记和工作区基础。

## 冻结点

- 任何工具不能绕过 `policy -> approval -> execute -> audit`。
- Shell 默认关闭。
- 未实现 OS 级隔离前，不把应用层路径校验宣传为完整沙箱。
- 工具输出只是数据，不得改变系统指令。

## 验收

- 路径穿越、symlink/junction、UNC、大小写变体测试。
- 内网地址、重定向、DNS 变化与超时测试。
- 审批超时、重启恢复和重复决定测试。
- 命令超时后的子进程清理测试。
