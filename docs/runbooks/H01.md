## 允许修改

- 根目录 `Cargo.toml`、`rust-toolchain.toml`、`.gitignore`
- `crates/hive-types/`
- `crates/hive-config/`

## 禁止修改

- 已冻结的 `docs/ARCHITECTURE.md` 与 `docs/PROTOCOL.md`，除非先提出 ADR
- 其他阶段的目录
- 用户已有的外部规格文档
- 不自动 commit、push 或安装 Rust 工具链

## 交付

- 可解析的 workspace 配置。
- 带版本号的 ID/状态/错误类型。
- 不读取密钥的配置加载与校验。
- `hive doctor` 最小实现，至少报告版本、模式、目录与工具链状态。
- 单元测试覆盖 ID、状态转移和配置校验的关键不变量。
- H01 handoff。

实现必须遵循 `docs/PROTOCOL.md`、ADR 0002、ADR 0003 与 ADR 0004，尤其是：

- `event_id` 与 `seq` 分离。
- Node 包含 `failed_final`/`needs_recovery` 等状态。
- `attempt_no` 与租约 token 分离。
- Approval 状态与超时语义不得自行改写。
