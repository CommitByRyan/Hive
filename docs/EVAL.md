# 评估基线

> 初始为空，H10 负责填充。所有结果必须记录模型、硬件、并发、任务集和 commit。

## 任务类别

1. 多路独立研究任务。
2. 多模块代码修改与合并。
3. 研究 -> 写作 -> 审阅 -> 修订的交接任务。
4. 单 Agent 失败、超时或上下文耗尽后的恢复任务。

## 指标

- 任务成功率。
- 人工接管率。
- 重复工作与文件冲突率。
- 输入/输出 token 与成本。
- 端到端墙钟时间、P50/P95 调度延迟。
- 峰值内存、事件写入量、数据库增长。
- 强杀重启后的恢复结果。
- 模型路由的可用性、结构和工具调用成功率。

## 验收原则

Python 原型、Rust 单 Agent、Rust DAG 并行必须使用同一模型、同一任务和同一硬件条件比较。没有实测不写性能结论。
