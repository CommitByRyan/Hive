# ADR 0004：安全边界承诺

- 状态：accepted
- 日期：2026-11-23

## 决定

1. 网络工具必须对解析后的地址做公网校验，并连接到已校验地址；禁止自动跟随重定向，或对每一跳重新校验。
2. 未实现连接级 IP 绑定时，必须标记“应用层 SSRF 限制，未防 DNS rebinding”，不得声称完整防护。
3. 路径工具必须测试 Windows 短路径、junction、symlink、UNC、驱动器相对路径和大小写变体；只做字符串前缀判断不算完成。
4. Shell 默认关闭，启用后逐次审批；未实现 OS 级隔离时不得宣传为完整沙箱。
5. 所有工具统一走 `policy -> approval -> execute -> audit`。

## 原因

R01 发现契约要求强于 Python 原型已有能力。明确实现门槛和降级声明，避免 H03 以应用层校验冒充连接级安全。

## 代价

- H03 的安全实现和测试量增加。
- 在 OS 级隔离完成前，产品必须展示限制，而不是只展示“已开启沙箱”。
