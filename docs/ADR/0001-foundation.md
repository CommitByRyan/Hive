# ADR 0001：本地单进程 Rust 内核

- 状态：accepted for H01
- 日期：2026-11-23

## 决定

Hive 第一版采用本地优先的单进程 Rust 内核，逻辑组件分 crate；HTTP、CLI 和后续 JSON-RPC 只是客户端边界。任务执行使用持久化 DAG 和事件日志。

## 原因

- 本地工作台不需要分布式复杂度。
- 单进程共享状态便于恢复、审批和调试。
- crate 边界足以控制依赖和维护代码所有权。
- 后续确有跨机器需求时，再通过协议边界拆分服务。

## 代价

- 进程崩溃会中断所有正在运行的任务，必须靠持久化恢复。
- 单进程内的某个 panic/资源耗尽仍可能影响其他任务，需要隔离和监控。
- 资源配额与背压必须由内核自己实现。
